# 2 计算方法

## 2.1 计算流程

1. 体系构建：读入数据文件 water_4096.data，体系含 4096 个 TIP4P/2005 水分子，共 12288 个原子，置于立方盒子中。
2. 初始化：按 298.0 K 的高斯分布生成初始速度。
3. 平衡：先进行 100 ps 的 NVT 平衡 【待确认：NVT 平衡的输入文件未提供，请补充其控温方式与参数】。
4. 生产：在 NPT 系综下运行 500000 步，输出每 1000 步的热力学量。
5. 分析：密度取生产段后 500 ps 的平均值。

## 2.2 力场与模拟参数

采用 TIP4P/2005 水模型，非键相互作用为 lj/cut/tip4p/long，截断 12.0 Å，长程静电用 PPPM（精度 1.0e-5），并用 SHAKE 约束水分子几何（容差 0.0001）。时间步长为 2.0 fs 【待作者确认：C1 输入文件为 2.0 fs，笔记写 1 fs（与 Vega 2005 一致）；正文按实际输入文件写 2.0 fs】，因此 500000 步对应 1 ns，与笔记中的 1 ns 生产时长一致。温度控制在 298.0 K（阻尼 100.0），压强 1.0 atm（阻尼 1000.0）各向同性耦合；LAMMPS 采用 real 单位制。
