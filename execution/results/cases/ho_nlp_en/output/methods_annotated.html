4.6 Limitations

- Model selection and reporting both use the 872-sentence validation split [F37: train_lora_s1.log:3; F38: train_lora_s1.log:3; F48: train_lora_s1.log:3; F58: train_lora_s1.log:3; F59: train_lora_s1.log:3], so the reported accuracy is optimistically biased.

- Only one model (roberta-large) [F66: conf/lora.yaml:2] and one task (SST-2) [F32: run_glue.py:10; F33: run_glue.py:10; F34: run_glue.py:10] were tested.

- Only 3 seeds per method [F19: results.csv:2; F20: results.csv:2; F21: results.csv:3; F22: results.csv:3; F23: results.csv:4; F24: results.csv:4]; the baseline used 10 epochs against 20 for LoRA [F64: conf/full_ft.yaml:9; F79: conf/lora.yaml:18], so the budgets differ.
