3 方法与实验

3.1 方法步骤

1. 数据清洗：输入为原始数据包 thucnews_2016.zip（共 74000 篇文档）[F60: logs/preprocess.log:1; F55: logs/preprocess.log:2]；运行 src/preprocess.py，剔除长度不在 [20, 2000] 字符范围内的文档 1210 篇 [F104: src/preprocess.py:4; F105: src/preprocess.py:5; F56: logs/preprocess.log:3]，再按全文精确去重剔除 790 篇 [F57: logs/preprocess.log:4]；输出为保留的 72000 篇文档 [calc: 74000-1210-790]。

2. 数据划分：先以 test_size=0.2 分层抽取 [F106: src/preprocess.py:10]，再将剩余部分按 test_size=0.5 等分为验证集与测试集 [F108: src/preprocess.py:11]，两次划分的随机种子均为 2023 [F107: src/preprocess.py:10; F109: src/preprocess.py:11]；输出训练集 57600 条、验证集 7200 条、测试集 7200 条 [F62: logs/preprocess.log:5; F63: logs/preprocess.log:5; F64: logs/preprocess.log:5]，与数据说明中的 8:1:1 划分一致 [F9: data_card.md:7; F12: data_card.md:7]。

3. 模型微调：以 src/train.py 加载预训练模型 bert-base-chinese [F30: configs/train.yaml:3]，在训练集上微调 5 个 epoch [F68: logs/train_bert_seed42.log:5]，每个 epoch 结束后在验证集上计算 macro-F1 [F48: configs/train.yaml:24]。

4. 检查点选择与测试：按验证集 macro-F1 选择第 4 个 epoch 的检查点 [F76: logs/train_bert_seed42.log:11]，测试集只评测一次 [F18: notes.md:5]。

5. 基线：以 src/baseline.py 训练 TF-IDF + 逻辑回归基线 [F24: configs/baseline_tfidf.yaml:2]，在同一测试集上评测 [F53: logs/baseline.log:1]。

3.2 实验设置

微调在 1 块 NVIDIA A100-SXM4-80GB 上完成 [F98: logs/train_bert_seed42.log:3; F99: logs/train_bert_seed42.log:3]，软件环境为 PyTorch 2.1.2+cu121、CUDA 12.1 [F95: logs/train_bert_seed42.log:2; F96: logs/train_bert_seed42.log:2]、transformers 4.36.2 与 scikit-learn 1.3.2 [F20: requirements.txt:2; F21: requirements.txt:3]，训练启用 fp16 混合精度 [F46: configs/train.yaml:21]。numpy 仅给出版本下限 >=1.24 [F22: requirements.txt:4] 【待确认：请提供实际安装的 numpy 版本（pip freeze）】。

3.3 数据集与划分

实验使用 THUCNews 的 10 类子集 [F1: data_card.md:2; F37: configs/train.yaml:11]，数据来源为 http://thuctc.thunlp.org/ [F3: data_card.md:3]，许可为仅限研究使用 [F4: data_card.md:4]。原始数据包下载于 2024-02-28 [F11: data_card.md:5]；THUCNews 本身未给出版本号 【待确认：请确认所用 THUCNews 发布版本或在论文中以下载日期作为版本标识】。划分方式见 3.1 第 2 步。

3.5 对照实验与评价

主要评价指标为测试集 macro-F1，同时报告准确率 [F48: configs/train.yaml:24; F78: logs/train_bert_seed42.log:12]。BERT 与 TF-IDF 基线使用同一划分的训练集与测试集 [F53: logs/baseline.log:1; F90: logs/train_bert_seed42.log:1]；基线未做超参数搜索 [F17: notes.md:4]，因此两者的调参预算不同。每个模型只运行了一次（BERT 种子 42）[F16: notes.md:3; F69: logs/train_bert_seed42.log:5] 【待确认：是否补充多种子重复实验并报告均值±标准差？】；未进行统计检验 【待确认：是否需要对 BERT 与基线的差异做显著性检验（如配对 bootstrap）？】。

3.6 可复现性

代码版本为提交 9f3c2ab [F65: logs/train_bert_seed42.log:4]。依次运行以下命令可复现数据划分、BERT 微调和基线：

python src/preprocess.py --raw data/raw/thucnews_2016.zip --out data/
python src/train.py --config configs/train.yaml --lr 2e-5 --epochs 5 --seed 42
python src/baseline.py --config configs/baseline_tfidf.yaml

训练随机种子为 42 [F69: logs/train_bert_seed42.log:5]，数据划分种子为 2023 [F107: src/preprocess.py:10]。

3.7 限制条件

- 所有结果来自单一种子（42）的单次运行 [F16: notes.md:3]，未估计随机初始化带来的方差。

- 基线未调参而 BERT 使用了经调整的学习率 [F14: notes.md:2; F17: notes.md:4]，比较不在相同调参预算下进行。

- 仅在 THUCNews 10 类子集、长度 20–2000 字符的文档上评测 [F37: configs/train.yaml:11; F104: src/preprocess.py:4; F105: src/preprocess.py:5]，更长文档会被 256 的最大序列长度截断 [F70: logs/train_bert_seed42.log:5]，其效果未测试。

- 仅在单块 A100 上训练 [F98: logs/train_bert_seed42.log:3]，未验证其他硬件与 fp16 关闭时的结果。
